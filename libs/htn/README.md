# libs/htn

`libs/htn` — ядро HTN‑планирования, используемое Planner и Analyst Worker.
Здесь будут описаны структуры задач, методы разложения и эвристики выбора.

## Компоненты
- Типы `Task`, `Method`, `PlanNode`, `DecompositionResult`.
- Реестр методов по доменам (загрузка из YAML/py‑модулей).
- Алгоритмы поиска: depth‑first, best‑first, ограничение по стоимости.
- Обработка репланов и табу‑списков.

## Пример интерфейса
```python
from libs.htn.engine import Planner
plan = Planner(method_registry).build(goal, context, constraints)
```

## Расширение
- Добавляйте новые методы в подкаталог `methods/` с описанием предусловий и
  постусловий.
- Храните эвристику стоимости отдельно, чтобы можно было подменить стратегию.
- Предусмотрите сериализацию плана для логирования и тестирования.

## Тестирование
- Пишите property‑tests на отсутствие циклов и соблюдение ограничений глубины.
- Добавляйте фикстуры с реальными задачами (goal → ожидаемое дерево).
- Проверяйте deterministic‑mode (одинаковый результат при одинаковых входах).
