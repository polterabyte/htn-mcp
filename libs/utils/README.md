# libs/utils

`libs/utils` — набор вспомогательных функций, которые не привязаны к конкретной
службе, но облегчают разработку. Здесь удобно хранить хелперы для логирования,
метрик, сериализации, генерации ID и работы с временем.

## Идеи для наполнения
- Форматирование структурированных логов (`structlog`, JSON‑формат).
- Генераторы идентификаторов (`short_uuid`, `trace_id`).
- Хелперы для работы с временными ограничениями (дедлайны, SLA окна).
- Утилиты для безопасной работы с конфиденциальными данными (редакция логов).

## Использование
```python
from libs.utils.time import utcnow, deadline_remaining
from libs.utils.logging import setup_logging
```

## Рекомендации
- Не добавляйте сюда зависимости от конкретных сервисов — только общий код.
- Старайтесь покрывать функции юнит‑тестами, особенно связанными с временем и
  сериализацией.
- Если утилита начинает зависеть от внешних сервисов — перенесите её в `libs/infra`.
