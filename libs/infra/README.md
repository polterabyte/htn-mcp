# libs/infra

`libs/infra` — набор инфраструктурных клиентов и общих обёрток. Цель — иметь
одну реализацию подключения к Postgres, Redis, NATS, S3/MinIO и средствам
наблюдаемости.

## Планируемое содержимое
- Универсальные клиенты (async/await) к Postgres, Redis, NATS.
- Хелперы для настройки `opentelemetry`, Prometheus и структурных логов.
- Обёртки над секретами (Vault/Kubernetes Secrets).
- Механизмы ретраев, circuit breaker, rate limiter.

## Использование
```python
from libs.infra.postgres import create_pool
from libs.infra.nats import NATSBus
```

## Лучшие практики
- Все клиенты должны поддерживать конфиг через Pydantic‑модели.
- Добавляйте метрики и логирование прямо в обёртки, чтобы сервисы получали их «из коробки».
- Документируйте требования к переменным окружения (`DATABASE_URL`, `NATS_URL`, ...).

## Тесты
- Пишите интеграционные тесты с `docker-compose` сервисами.
- Используйте моки для негативных сценариев (разрывы соединений).
