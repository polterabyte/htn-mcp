# Итоги анализа проекта HTN-MCP

## Сильные стороны
- **Чёткая архитектурная документация.** Файлы `ARCHITECTURE.md`, `PROJECT_STRUCTURE.md`
  и дизайн-док покрывают ключевые компоненты, интеграции и стандарты.
- **Подготовленная инфраструктура для локальной разработки.** В `docker-compose.yml`
  уже определены Postgres, Redis, NATS, MinIO, стек наблюдаемости и базовые сервисы.
- **Продуманные точки расширения.** Структура каталогов (`apps/*`, `libs/*`, `schemas/`)
  позволяет параллельно развивать сервисы и общие библиотеки.
- **Фокус на наблюдаемость и безопасность.** В проекте предусмотрены метрики,
  OpenTelemetry, политики доступа к Blackboard и MCP.

## Слабые стороны
- **Много заглушек.** Большинство сервисов содержат только каркас без
  бизнес-логики, методов планирования и FSM контрактов.
- **Отсутствие тестовой базы.** Нет юнит-, интеграционных и e2e-тестов, что
  осложняет контроль качества.
- **Не описан процесс QA и инцидент-менеджмента.** Документы `QA_STRATEGY.md`
  и `RUNBOOKS.md` требуют заполнения.
- **Нет автоматизации CI/CD.** В `.github` отсутствуют workflows, нет описанных
  пайплайнов сборки и публикации пакетов `libs/*`.

## Рекомендации по улучшению
1. **Реализовать минимально жизнеспособный сценарий.** Настроить цепочку:
   Orchestrator → Planner → Contract Manager → Executor → Verifier, используя
   NATS и Blackboard. Это даст сквозной happy-path.
2. **Заполнить общие библиотеки.** Добавить модели контрактов, HTN-ядро и
   MCP-клиенты, синхронизировав их с JSON-схемами.
3. **Наладить тестирование.** Описать стратегию в `docs/QA_STRATEGY.md`, создать
  базовые pytest-наборы для сервисов и интеграционные тесты с docker compose.
4. **Добавить CI/CD.** Настроить GitHub Actions/другой пайплайн для линтеров,
  тестов, сборки образов и публикации пакетов.
5. **Доработать runbooks и процессы поддержки.** Задокументировать действия при
  сбоях MCP, переполнении очередей, проблемах с Blackboard.
6. **Продолжить работу над наблюдаемостью.** Реализовать экспозицию метрик и
  трейсов в коде сервисов, добавить дешборды Grafana и алерты Prometheus.
