# HTN + MCP Multi-Agent System

Этот репозиторий содержит заготовку многоагентной платформы, где цели
пользователей решаются через HTN‑планирование и контракты между ролевыми
агентами. Листовые действия выполняются через MCP‑инструменты.

## Как быстро разобраться
1. Прочитайте [ARCHITECTURE.md](ARCHITECTURE.md) и `docs/design/README.md` — это
   объяснит роли сервисов.
2. Посмотрите `PROJECT_STRUCTURE.md`, чтобы понять назначение каталогов.
3. Для каждого сервиса/библиотеки загляните в его `README.md` — все они
   наполнены конкретными подсказками для новичков.

## Локальный запуск
```bash
make up        # поднять весь стек через docker compose
make logs      # посмотреть логи
make down      # остановить и очистить
```

## Что реализовано сейчас
- Стартовые каркасы сервисов (FastAPI/воркеры) и общие библиотеки.
- Инфраструктура для локального запуска: Postgres, Redis, NATS, MinIO,
  Prometheus, Grafana, Loki, OTEL Collector.
- Документация по архитектуре, структуре проекта, контрактам и MCP‑инструментам.

## Что предстоит сделать
- Заполнить библиотеки (`libs/*`) реальной логикой.
- Подключить реальные базы/очереди и реализовать обмен событиями.
- Добавить тесты (юнит, интеграционные, e2e) и настроить CI/CD.
